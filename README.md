# CourseMaster - Backend (Debugged)

A REST API backend for CourseMaster, a modern e-learning platform. This repository contains the backend application being reviewed and improved as part of a bug-bashing and debugging assessment.

Original Backend Repository: [courseMaster_Backend](https://github.com/Pullock4981/courseMaster_Backend)

## Project Name & Description

**CourseMaster** is a full-featured e-learning platform where students can browse courses, enroll in learning programs, watch video lectures, submit assignments, and take quizzes. Administrators can manage courses, monitor enrollments, review student submissions, and access analytics.

The backend provides API endpoints and server-side functionality to support authentication, course management, enrollment operations, assignments, quizzes, and administrative features.

This repository contains the backend codebase used for the debugging assessment. The objective is to identify reproducible defects, fix backend issues, improve error handling and code quality, and verify that existing functionality continues to work correctly.
